# Laptop Price Analysis Project

## Project Overview

This project focuses on analyzing a dataset of laptop specifications and prices to uncover insights that can help consumers and businesses make informed decisions. The analysis aims to identify trends, patterns, and relationships between laptop features and their prices.

The project demonstrates skills in data cleaning, exploratory data analysis (EDA), visualization, and data-driven insights.

## Dataset

* The dataset contains over 1,000 rows of laptop data.
* Key columns include:

  * **Company** – Laptop manufacturer
  * **Product** – Laptop model
  * **TypeName** – Laptop type (e.g., Ultrabook, Gaming, Notebook)
  * **Inches** – Screen size
  * **Resolution** – Screen resolution
  * **CPU** – Processor details
  * **RAM** – Memory size
  * **Storage** – HDD/SSD storage details
  * **GPU** – Graphics card
  * **OS** – Operating system
  * **Price** – Laptop price (target variable)

## Objectives

1. **Data Cleaning**

   * Handle missing or inconsistent values.
   * Convert categorical and numerical features into usable formats.

2. **Exploratory Data Analysis (EDA)**

   * Analyze price distribution and key statistics.
   * Identify relationships between laptop features and price.
   * Detect outliers and unusual patterns.

3. **Visualization**

   * Use bar plots, scatter plots, and heatmaps to visualize trends.
   * Compare prices across different companies, types, and features.

4. **Insights & Findings**

   * Determine the most and least expensive laptops by brand.
   * Find which features most influence price.
   * Recommend laptops based on price-performance balance.

## Key Methods & Techniques

* **Sorting and Filtering** – Find highest and lowest priced laptops per brand.
* **GroupBy and Aggregation** – Calculate average price by company, type, or feature.
* **Conditional Logic** – Categorize laptops by size, price range, or performance.
* **Visualization Libraries** – Matplotlib, Seaborn, and Pandas plotting.

## Project Workflow

1. Load the dataset into a Pandas DataFrame.
2. Inspect and clean the data.
3. Perform feature engineering (e.g., convert RAM and storage to numeric values).
4. Conduct EDA to explore patterns and relationships.
5. Visualize findings using charts and graphs.
6. Summarize insights and make recommendations.

## Tools & Libraries

* **Python** – Programming language
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical computations
* **Matplotlib & Seaborn** – Data visualization
* **Jupyter Notebook** – Interactive analysis environment

## Conclusion

This project provides a detailed analysis of laptop prices and features, helping users make data-driven decisions when purchasing laptops. It demonstrates essential data analysis skills and practical applications of Python libraries for real-world datasets.
